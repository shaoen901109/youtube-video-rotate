# Security Policy / 安全性政策

## Reporting a vulnerability / 通報漏洞

If you find a security issue, please **do not open a public issue**. Email **shaoenstudio@gmail.com** with the details (affected file, steps to reproduce, impact). You will get a reply as soon as possible.

發現安全性問題時，請**不要開公開的 issue**，改寄信到 **shaoenstudio@gmail.com**，附上受影響的檔案、重現步驟與影響範圍，我會盡快回覆。

## Verifying downloads / 校驗下載檔

Every release on the [Releases](../../releases) page ships a zip, a `SHA256SUMS.txt` file and a GitHub build provenance attestation. See the "Verify your download" section of the README.

每個 [Releases](../../releases) 版本都附 zip、`SHA256SUMS.txt` 與 GitHub 來源證明（attestation），校驗方法見 README 的「校驗下載檔」段落。
